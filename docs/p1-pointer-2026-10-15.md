# DXGI 指针合成与连续采样

## 已实现

- 缓存 DXGI 指针形状与位置，按可见状态合成到 BGRA；支持 COLOR、MASKED_COLOR、MONOCHROME。
- COLOR 使用预乘 alpha 合成；masked color 按 alpha 选择替换或 XOR；单色形状按 AND/XOR 两平面处理。位置直接使用 DXGI 提供的形状左上角，不重复减 hotspot。
- 形状缓冲上限 4MiB，检查类型、pitch、长度和单色双平面高度；屏外裁剪，隐藏时跳过。优先复用独占 BGRA 缓冲，避免完整帧重复拷贝。
- 探针新增 `--seconds 1..60`，输出成功帧、超时、字节数和 capture 调用 p50/p95；超时不当作采集失败。

## 实测与测试

- `cargo run -p rd-capture --example dxgi_probe --locked -- 0 --recreate`：重建前后均获取 1920×1080 BGRA 帧，8,294,400 字节。
- 输出 0：10.02 秒，1 帧，92 次超时；成功采集调用 7.68ms。这是无更新样本，不构成动态帧率结论。
- 输出 1：10.01 秒，294 帧，2 次超时，29.37fps；capture 调用 p50/p95 为 5.07/13.94ms。
- 时间包含 Acquire 等待、readback 与指针处理，不包含编码、GPU 完成或屏幕呈现；probe 节拍为 33ms，debug 构建，非受控动态素材性能验收。未保存桌面像素。
- workspace 测试 53 项通过；之后追加的隐藏/屏外测试在 rd-capture 全部 12 项复测中通过。五项指针测试覆盖透明、裁剪、单色 AND/XOR、masked color、畸形缓冲、隐藏及屏外位置。
- 严格 clippy 成功，曾出现增量缓存拒绝访问警告；格式化后重新检查。
